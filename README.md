# Falsifier

> Disequilibrium screening and false-positive triage for exoplanet candidates.
> **This project is not a biosignature detector. No exoplanet biosignature has ever been confirmed.**

---

## What this project does

Falsifier takes a Kepler or TESS target and runs a reproducible, auditable pipeline:

1. **Ingest** — fetches calibrated light curves from MAST and stellar parameters from Gaia DR3
2. **Detrend** — removes systematics with `wotan` biweight; propagates time-system metadata verbatim from FITS headers
3. **Search** — runs `transitleastsquares` to identify Threshold Crossing Events (TCEs)
4. **Vet** — applies seven named tests; disposition is a deterministic function of those tests
5. **Classify** — XGBoost + isotonic calibration returns a calibrated probability (ranking score only; no verdict)
6. **Retrieve** — atmospheric retrieval for confirmed planet-hosting candidates (petitRADTRANS / CHIMERA / POSEIDON)
7. **Disequilibrium** — FastChem/VULCAN/Gibbs free energy screening on established planets only

The output is a triage list. It is not a detection claim.

## Non-negotiable rules

See [`AGENTS.md`](AGENTS.md) for the full policy spine.  Summary:

| Rule | Enforcement |
|---|---|
| No hardcoded scientific values in UI/API | `scripts/verify_readme.py` exits non-zero on drift |
| Every physical quantity carries `astropy.units` | Pydantic `UnitedArray` validators on all stage contracts |
| Every dataset records DOI + access date + row count | `tests/test_provenance_complete.py` |
| ML splits grouped by host star ID | `tests/test_no_leakage.py` asserts disjoint host sets |
| README claims regenerable by reproduce script | `scripts/verify_readme.py` wired into CI |
| Dead code declared explicitly | See §Dead / Experimental Code below |

## Repository layout

```
falsifier/pipeline/
  contracts/      Pydantic input/output models for every stage
  ingest/         MAST · TAP · Gaia sources + content-addressed cache
  classify/       Feature extraction · GroupShuffleSplit · XGBoost training
  stages/         Stage bodies (ingest, classify; detrend/search/vet pending)
  io.py           artifact_write / artifact_read / input_hash

data/
  golden/         Committed FITS files + provenance sidecars (network-free tests)
  splits/         Committed train/test split indices (written by training run)
  artifacts/      Pipeline run outputs (generated; not committed)

scripts/
  fetch_golden.py          Fetch golden FITS files from MAST (requires network)
  injection_recovery.py    Completeness test (synthetic transit injection)
  adversarial_selftest.py  False-alarm rate self-attack
  verify_readme.py         Diff README claims against committed artifacts
  reproduce.sh             Full reproducibility script (generates all claims)

tests/
  test_kepler10_recovery.py      Period recovery on Kepler-10b golden file
  test_known_eb_rejected.py      KIC 6965293 EB rejected via odd_even_depth
  test_no_leakage.py             Host-star split disjointness
  test_provenance_complete.py    DOI + access_date + row_count on all sidecars
  test_time_systems.py           BKJD/BTJD/JD round-trip, header enforcement
  test_injection_recovery.py     Unit tests for injection_recovery.py
  test_adversarial_selftest.py   Unit tests for adversarial_selftest.py
  pipeline/contracts/            Per-stage Pydantic contract tests
  pipeline/test_io.py            artifact_write/read/input_hash tests
```

## Running the tests

```bash
# Fast suite (no network, no FITS files required)
pytest tests/ \
  --ignore=tests/test_kepler10_recovery.py \
  --ignore=tests/test_known_eb_rejected.py \
  --ignore=tests/pipeline/stages/test_ingest.py \
  --ignore=tests/test_time_systems.py \
  -q

# Full suite (requires committed golden files and astropy installed)
pytest tests/ -q

# README claim verification
python scripts/verify_readme.py
```

## Self-assessment: what this pipeline can and cannot see

Run `python scripts/injection_recovery.py` to regenerate the completeness curve.
Run `python scripts/adversarial_selftest.py` to regenerate the false-alarm rates.

Both scripts exit 0 regardless of result. Low completeness and high false-alarm rates
are published as-is; they are not filtered before the artifact is committed.
